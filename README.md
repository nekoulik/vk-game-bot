# 🎮 Club Anicoke Bot — VK игровой бот

Полнофункциональный игровой бот для ВКонтакте с экономикой, сражениями, квестами и кланами.

## 📋 Возможности

### 💰 Экономика
- **Баланс** — проверка монет
- **Работа** — заработок монет (кулдаун 1 час)
- **Ежедневный бонус** — награда за вход
- **Топ игроков** — рейтинг по балансу

### ⚔️ Сражения
- **Дуэль с ботом** — бросок кубика на ставку
- **PvP** — сражения между игроками
- **Босс** — рейдовый босс с наградами

### 🛒 Магазин
- **Оружие** — увеличивает урон
- **Питомцы** — дают бонусы к монетам и урону
- **Зелья** — временные улучшения

### 📋 Квесты
Ежедневные задания:
- Трудолюбивый (поработать 3 раза)
- Дуэлянт (выиграть 2 дуэли)
- Охотник на боссов (нанести 500 урона)
- Ежедневный бонус (получить 1 раз)
- Игроман (сыграть 5 раз в мини-игры)

### 🏆 Сезонная система
- Очки сезона за активность
- Таблица лидеров
- Награды в конце сезона

### 🛡️ Кланы
- Создание и управление
- Приглашения участников
- Клановая казна
- Бонусы участникам

### 🎮 Мини-игры
- Камень-ножницы-бумага
- Угадай число
- Рулетка
- Монетка

### 🛠️ Админ-панель
- Выдача монет
- Бан / разбан
- Мут
- Сброс сезона
- Рассылка
- Управление беседой

## 🚀 Установка

### Требования
- Python 3.8+
- SQLite3
- VK API токен группы

### Шаги установки

1. **Клонируйте репозиторий**
   ```bash
   git clone <URL_РЕПОЗИТОРИЯ>
   cd vk-game-bot

2.Установите зависимости
   pip install -r requirements.txt

3.Настройте конфигурацию
   cp .env.example .env

Откройте .env и укажите свои данные:
VK_TOKEN=ваш_токен_группы
ADMIN_IDS=ваш_id,второй_id
GROUP_ID=id_группы

4.Запустите бота
   python main.py

⌨️ Основные команды

👤 Игрок
/помощь — список команд
/баланс — проверить баланс
/профиль — свой профиль
/работа — заработать монеты
/бонус — ежедневный бонус
/топ — топ игроков
/магазин — купить предметы
/инвентарь — свои вещи
/квесты — ежедневные задания
/босс — сразиться с боссом
/pvp — PvP статус
/клан — управление кланом

👑 Админ
/админ — админ-панель
/статистика — статистика бота
/выдать <id> <сумма> — выдать монеты
/бан <id> — забанить
/разбан <id> — разбанить
/мут <id> <минуты> — замутить
/сбросить сезон — сброс сезона
/рассылка <текст> — рассылка

📊 База данных

Бот использует SQLite. Основные таблицы:
players — игроки
boss — текущий босс
duels — дуэли
items — предметы
clans — кланы
chat_settings — настройки беседы
